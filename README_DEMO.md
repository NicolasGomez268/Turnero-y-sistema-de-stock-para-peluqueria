# 🎭 RAMA DEMO - TINCHO Barbería

## ⚠️ IMPORTANTE
Esta es la **rama de demostración** del proyecto. Está completamente separada de la rama de producción.

## 🎯 Propósito
- Mostrar el sistema a clientes potenciales
- Datos ficticios preconfigurados
- Base de datos independiente

## 🔗 URLs
- **Frontend Demo:** https://tincho-barberia-git-demo-nicolas-projects-962652f9.vercel.app
- **Backend Demo:** https://barberdemo.pythonanywhere.com
- **Frontend Producción:** https://tincho-barberia.vercel.app (NO SE VE AFECTADO)

## ⚙️ Configuración
- Backend separado en PythonAnywhere
- Base de datos SQLite independiente con datos de prueba
- Variables de entorno configuradas en `.env.production`

## 📊 Datos Demo
El sistema incluye:
- 3 barberos de ejemplo
- 5 servicios comunes
- 10 productos de inventario (capilares, ropa, accesorios)
- Turnos de muestra
- Usuario admin demo

## 🚀 Deployment
Vercel automáticamente despliega esta rama cuando se hace push.
